This preview page is not connected to a fixtures API, so it shows no matches, odds, statistics or predictions. The earlier preview used synthetic test clubs; it has been withdrawn and every recommendation it showed is void.

Run the app with API_FOOTBALL_KEY set to see today's real fixtures. python scripts/verify_today.py lists every displayed match next to its API-Football fixture id.

What every fixture must pass before it is analysed

  1. Fetch today's fixtures from the football API for the app's timezone.
  2. Filter to supported competitions.
  3. Verify by provider id: fixture exists, both team ids resolve to the same names, competition supported, kickoff on the selected date, not postponed or cancelled.
  4. Fetch statistics and bookmaker odds by provider id. No odds means ODDS UNAVAILABLE; too little history means DATA INCOMPLETE and no prediction.
  5. Run the models in backend code, then recompute every EV, fair price and implied probability. A mismatch rejects the recommendation and is logged.
  6. Recommend only on VERIFIED fixtures. The AI analyst only explains this verified data.

Verification statuses

VERIFIEDAll checks passed and odds exist. The only status that can produce recommendations.
UNVERIFIEDNO VERIFIED FIXTURE or TEAM NOT VERIFIED: the API did not confirm the fixture, a team or the competition.
ODDS UNAVAILABLEVerified fixture, but the odds API returned no prices. Model probabilities only, no bets.
DATA INCOMPLETENot enough statistics from the data provider. No prediction is shown.
POSTPONEDProvider status postponed, suspended or interrupted.
CANCELLEDProvider status cancelled, abandoned, awarded or walkover.
